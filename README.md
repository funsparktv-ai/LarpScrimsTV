# LarpScrimsTV

Live leaderboards for the LarpScrims community: player ratings (S+ to G-), Elo and community favourites, with a profile for every player.

The page is static. `data/leaderboard.json` is written by the LarpScrims bot every few minutes (only when something changed). Votes come from `/vote @player` in Discord.

The Discord widget only shows when **Server Settings → Widget → Enable Server Widget** is on.
